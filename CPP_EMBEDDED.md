# Embedded C++ companion
The Python file CLI remains unchanged. `cpp/core.hpp` implements the same RLE1 binary format using caller-owned fixed buffers: header `RLE1` followed by (run length 1..255, byte) pairs. Encoding and decoding preflight capacity and reject malformed headers, odd payloads, zero-length runs and insufficient output space without writing partial output. The caller must supply distinct non-overlapping input and output buffers and enforce a sensible maximum decoded size. RLE can expand incompressible input. No file system, streaming, encryption, wear-leveling or integrity checksum is provided. For Arduino Uno avoid large stack buffers; use bounded static storage. Do not use for safety-critical firmware updates without authenticated checksums/signatures.
Run: `cmake -S . -B build && cmake --build build && ctest --test-dir build --output-on-failure`. Python regression: `python -m unittest discover -s tests -v`. No board or hardware validation claimed.
